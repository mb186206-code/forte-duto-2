Política de privacidade

Esta política explica como a Forte Duto trata os dados pessoais informados por quem solicita orçamento pelo site, conforme a Lei Geral de Proteção de Dados (Lei nº 13.709/2018).

Quais dados recebemos

Ao usar o formulário de orçamento, você informa nome, telefone, bairro ou região, tipo de problema e, se quiser, uma descrição. Esses dados são usados para montar uma mensagem que abre no seu WhatsApp. Este site não grava nem envia esses dados para nenhum servidor: eles só chegam à Forte Duto se você enviar a mensagem pelo WhatsApp.

Para que usamos

Para responder ao seu pedido, avaliar o serviço, combinar orçamento e agendar o atendimento. Não vendemos nem compartilhamos seus dados para publicidade.

Onde ficam guardados

As conversas ficam no WhatsApp, serviço da Meta, sujeito à política de privacidade dele. Mantemos as informações pelo tempo necessário para o atendimento e para cumprir obrigações legais.

Cookies e ferramentas de medição

Este site não usa cookies de rastreamento nem ferramentas de análise de visitas. Se isso mudar, esta política será atualizada antes.

Seus direitos

Você pode pedir acesso, correção ou exclusão dos seus dados a qualquer momento pelo WhatsApp {{PHONE_DISPLAY}}.
